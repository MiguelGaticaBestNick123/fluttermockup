# StockLite - Sistema de Gestión de Inventario

¡Hola! Bienvenido a StockLite. Este es un sistema simple pero poderoso para manejar tus productos, clientes y ventas.

## Cómo empezar
1. Asegúrate de tener Flutter instalado.
2. Configura las variables de entorno para Supabase (URL y Key).
3. Corre la app: `flutter run`

¡Y listo! Ya no necesitamos correr Python porque nos mudamos a la nube con Supabase 8)

## Características
- Gestión de productos (con fotos y todo :v)
- Clientes (para saber a quién cobrarle)
- Ventas (¡a hacer dinero!)
- Modo Offline (puedes vender sin internet y se sincroniza luego)

## Nota
Si ves errores raros, revisa tu conexión a internet. Aunque funciona offline, necesita conectarse de vez en cuando para guardar todo en la nube :p
